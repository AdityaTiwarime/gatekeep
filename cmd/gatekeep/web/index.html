GateKeep

An OpenID Connect identity provider and an authenticating reverse proxy, written in Go with only the standard library. This page is a real OIDC client: it signs in with the authorization code flow and PKCE, then calls a backend that sits behind the proxy.

3 Token lifecycle

    

      
      
      
      
    

    
Refresh tokens rotate on every use. Replaying an old one looks like theft, so the whole session is revoked. After a key rotation, old tokens keep working until they expire, because the old public key stays in the JWKS for a grace period.
